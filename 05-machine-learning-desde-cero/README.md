# 05 — Machine learning desde cero (con NumPy, sin magia)

## La idea en criollo

Aquí se juntan los módulos 01-04: cada modelo clásico es una fórmula con parámetros, un error a minimizar y un algoritmo para minimizarlo. Si lo programas tú con NumPy, ninguna librería vuelve a ser una caja negra.

## Lo que vas a aprender aquí

- **Regresión lineal**: la recta que mejor explica los datos, resuelta de dos formas (fórmula cerrada y descenso de gradiente).
- **Regresión logística**: la misma idea, pero para clasificar (sí/no) con la sigmoide.
- **k-means**: agrupar sin etiquetas, solo con distancias.
- **PCA**: comprimir dimensiones con SVD, quedándote con lo que más importa.
- Overfitting / underfitting y validación: por qué un modelo que memoriza no sirve.
